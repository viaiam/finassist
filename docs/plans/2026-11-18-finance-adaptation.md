# 金融最小适配实施计划

目标：复用现有对话引擎、会话仓储、槽位状态机和 Vue 布局，接入独立金融样例库。

1. 增加只读中台金融接口；按 customer_no 与业务对象归属共同筛选，绑定所有 SQL 输入。
2. 先运行金融 API 测试确认缺失模块报错，再实现账户、交易、贷款、还款与产品适配。
3. 沿用四类任务命令和对象填槽，用四条金融 YAML 流程替换订单演示配置。
4. 替换知识意图、provider 及四份提示词，明确未实现业务，不虚构规则或办理成功。
5. 页面复用聊天与卡片布局，展示账户、贷款、贷款产品和理财产品；读取真实样例客户。
6. 验证所属客户隔离、日期校验、空结果、动作注册、流程执行和前端构建。

不修改原始资料，不删库，不实现资金操作与金融申请写入。
已有订单历史保留；旧流程任务在本轮使用金融样例客户独立会话，不自动迁移旧任务。
